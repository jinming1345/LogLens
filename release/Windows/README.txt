使用方式：
  双击 LogLens.exe 即可运行，无需安装。

系统要求：
  - Windows 10 (1803+) 或 Windows 11
  - WebView2 Runtime（Windows 10/11 通常已预装）
    如未安装，请访问：https://developer.microsoft.com/microsoft-edge/webview2/

功能简介：
  - 高性能日志查看器，支持百万行虚拟滚动
  - 智能过滤：多关键词 AND/OR、正则表达式、时间范围、日志等级
  - 支持格式：.log .txt .json .csv .xml 等
  - 拖拽打开文件/文件夹
  - 浅色/深色主题、中英双语
  - 实时监控 Tail 模式
  - 数据看板、书签、导出

快捷键：
  Ctrl+O        打开文件
  Ctrl+Shift+O  打开文件夹
  Ctrl+K        切换过滤面板
  Ctrl+F        聚焦搜索
  Ctrl+,        打开设置
  Escape        关闭过滤面板
