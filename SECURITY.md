# Security Policy / 安全策略

## Supported Versions / 支持的版本

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes     |

## Reporting a Vulnerability / 报告安全漏洞

If you discover a security vulnerability, please report it responsibly:

如果你发现安全漏洞，请负责任地报告：

1. **Do NOT** create a public issue / **不要**创建公开 issue
2. Email the maintainer directly or use GitHub's [private vulnerability reporting](https://github.com/jinming1345/LogLens/security/advisories/new)
3. Include:
   - Description of the vulnerability / 漏洞描述
   - Steps to reproduce / 复现步骤
   - Potential impact / 潜在影响

We will respond within 48 hours. / 我们将在 48 小时内回复。
